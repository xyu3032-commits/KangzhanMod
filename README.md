# 烽火抗战 KangzhanMod

《烽火抗战》是 DroneFlames（0.33）的剧情战役模组：中日战争题材，中国 vs 日本双阵营。

- **129 种二战单位 / 132 座建筑**，全套二战造型（T-26、维克斯、九七式改、P-40、零式、赤城、装甲列车等）
- **7 章单局连续战役**：卢沟桥 → 平型关 → 台儿庄 → 百团大战 → 长沙 → 滇缅反攻 → 全面反攻；每章有剧情抉择，影响后续战局（含跨章连锁）
- 战役世界固定格局：开局即中国 9 城对日本 4 城、首都预设重庆/东京；基地与部队跨章继承，章节失败可从章节起点快照重试；第 3 章起有美国远程支援
- 另含**自由对局模式**与左上角 GM 面板（无限资源 / 无限兵力 / 无敌 / 一键补满）

## 安装

1. **游戏内导入**：在游戏的模组管理里选择「导入」，选中下载的 `.dfmod` 文件，启用《烽火抗战》。
2. **文件夹放入**：把 `.dfmod` 放到手机的 `Download/DroneFlamesMods` 目录，再在游戏内导入/启用。
